WEEK 1: SEPT 14th

This week, I looked at one of the recommended readings on the course website, Experiments with Google. I also studied the week one introduction and learned many important and basic things about the internet. It helped me understand the basic idea of how the internet communicates and how different parts are connected.

By exploring the Experiments with Google website, I found that Google provides many interesting platforms and tools for creators. I also noticed that many of the projects are simple to access and easy to understand. I did not need to spend much time learning how to use the website before I could start exploring.

Before looking at this website, I did not realize that a simple design could still have so many different functions. Many of the art projects have very clean and simple interfaces, but they allow users to do many interesting things. For example, users can play music together with other people, create their own web tags, and use generators to turn music into visual art. This made me realize that good user experience does not need to be complicated.

Looking at these projects also gave me ideas for my own future work. I want to create websites that are simple to use but still interesting, creative and interactive.

WEEK 2: SEPT 21st

This week, I explored the Random Darknet Shopper project from the course website. The project uses an automated bot that randomly buys items from the darknet with a weekly budget. I found this project very interesting because the bot can make choices and complete actions automatically. It also made me think about who is responsible when a program does something unexpected or even illegal.

Before looking at this project, I mostly thought of coding as a tool for building websites or making programs work. This project showed me that code can also become part of an artwork and can be used to create an idea or experience for the audience. I think this makes digital art very different from traditional art because the program itself can actually perform actions.

This week, I also started learning the basic Python. I find that python easier to use and understand than JavaScript. I learned some basic concepts such as variables, different data types, if statement, while loop, and functions. At first, some of the syntax was confusing, but after practicing with small exercises, I started to understand how Python reads instructions step by step.
