WEEK 3: SEPT 28th

This week,I explored The sheep Market by Aaron Koblin. In this project, many people were asked to draw a sheep facing left. Even though everyone got the same instruction, every sheep looked different. I found this very interesting becuase one simple rule could create many different results.

Before I saw this project, I thought an artwork was usually made directly by one artist. However, The Sheep Market changed my idea. The artist created the system and the rule, but many other people made the drawings. I think the final work is created by both the artist's idea and the different people who joined the project.

This week, I also learned more about Python, including lists, dictonaries, APIs, and the Rich library. I learned that lists and dictionaries can help us organize data, and APIs can help us get data from other websites. I found Rich very interesting because it can add colors and styles to data in the terminal. This makes the information easier to read and more interesting to look at.

This week made me understand that coding is not only about making a program work.It can also change how users see and understand information.

WEEK 4: OCT 26th

This week, I explored a project called Dead Drops by Aram Bartholl. In this project, USB drives were installed in public spaces, such as walls and buildings. People can connect their computers to these USB drives to share or download files without using the internet. I found this very interesting because we usually use the internet to share information, but this project shows a different way.

Before I saw this project, I thought sharing digital information always needed the internet or some online platforms. However, Dead Drops changed my idea. I think it is interesting that people need to visit a real location to share files. It also makes digital communication become part of the physical world.

This week, I also started learning about Flask, which is a Python framework for building websites. I learned that routes can connect different URLs to Python functions. I also learned about templates, which allow us to use Python variables in HTML. I found this interesting because I did not know Python could be used to build websites in this way.

This week made me understand that there are many different ways to share information. Dead Drops uses physical locations, while Flask helps us create websites to share information online.
